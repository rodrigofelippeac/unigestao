# Do / Don't — documentação (unigestao)

## ❌ NUNCA
- Criar documentação redundante com o que já está no `CLAUDE.md`.
- Documentar código óbvio ("este arquivo exporta X").
- Deixar `progresso.md` desatualizado após mudanças significativas.
- Criar ADR sem descrever o contexto que motivou a decisão.
- **Modificar arquivos de código fonte** — este papel só documenta.

## ⚠️ Git/permissões
- Confirmar com o usuário antes de commit/push; nunca `--force`/`--no-verify`/
  reescrever histórico sem pedido. Git é das skills do projeto.
