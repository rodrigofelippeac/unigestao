# Estrutura — design/identidade (unigestao)

- `briefing/` — assets de branding: paleta, logos (horizontal e vertical),
  referências visuais, banners.
- `CLAUDE.md` — identidade visual documentada (cores, logo, princípios).
- `frontend/src/styles/globals.css` — onde os tokens viram CSS Custom Properties
  (handoff para o `frontend`).

## Subdomínios de atuação
Identidade visual, design system (tokens/componentes/variantes/estados), layout
de telas (grid/espaçamento/hierarquia), UX/fluxos/micro-interações,
acessibilidade (WCAG), responsividade, especificação/handoff (tokens CSS).
